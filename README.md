# V-Able Web Araçları / V-Able Web Tools

V-Able Bilişsel Bilimler Laboratuvarı'nın (Recep Tayyip Erdoğan Üniversitesi, Eğitim Fakültesi) etkileşimli eğitim ve araştırma araçları. Laboratuvar Yürütücüsü: Dr. Emre Cumalı. Site: https://vable.erdogan.edu.tr

Interactive learning and research tools of the V-Able Cognitive Science Lab (Recep Tayyip Erdoğan University, Faculty of Education).

| Araç / Tool | Adres / URL |
|---|---|
| EEG Atlası / EEG Atlas | https://emrecumali-cogsci.github.io/vable-araclar/eeg-egitim/ |
| Göz Takibi Atlası / Eye-Tracking Atlas | https://emrecumali-cogsci.github.io/vable-araclar/goz-takibi/ |
| Pilot EEG Kaydı / Pilot EEG Recording | https://emrecumali-cogsci.github.io/vable-araclar/eeg-pilot/ |
| Örneklem Büyüklüğü Hesaplayıcı / Sample Size Calculator | https://emrecumali-cogsci.github.io/vable-araclar/orneklem/ |
| Tek Denekli Araştırma Analiz Aracı / Single-Case Design Analyzer | https://emrecumali-cogsci.github.io/vable-araclar/tek-denekli/ |
